# Auro

I build agent-native developer tools and local-first product surfaces:
cross-harness skill and agent management, TypeScript/React apps, orchestration
UI, tmux-based workflows, and practical engineering systems.

My strongest work sits where product engineering, complex state, and AI agent
workflows meet: long-running tasks, approvals, retries, tool calls, session
handoff, and the developer experience around all of it.
